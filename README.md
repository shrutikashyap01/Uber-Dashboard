# 🚖 Uber Ride Analysis Dashboard

## 📌 Overview
This project is an interactive **Power BI Dashboard** analyzing Uber ride data.  
It provides insights into ride demand, customer behavior, revenue trends, and cancellations.  

## 🛠 Tools & Technologies
- Power BI  
- SQL (for preprocessing & data cleaning)  
- Excel (for initial exploration)  

## 📊 Key Insights
- Peak demand occurs on **weekends and evenings**.  
- **40% of rides** come from a few high-demand locations.  
- Customer cancellation rate reduced when **drivers were allocated efficiently**.
